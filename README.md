# AI Workspace Assistant
This is an AI assistant that will assist with generating emails, summarizing meeting notes and scheduling tasks in the workspace.
This intelligent, LLM-powered productivity agent is designed to streamline your daily workflow.

## Project Overview
Managing communication, documentation, and action items take a considerable amount of time. This project aims to solve the problem by providing an AI assistant that connects your communication channels and calendar. It acts as virtual staff, turning messy text into structured, actionable items.

## Core Features
#### Email Generation
Drafts emails with context, refines the tones (formal, casual, persuasive), and creates quick replies based on brief prompts.

#### Meeting Summarizer
Compiles meeting notes and transcripts into summaries, key decisions and updates.

#### Task Planner
Automatically extracts deadlines and action items from meetings or emails and organizes them into a priority-based task list.

#### Built-in Persistence
Saves all your generated tasks, summaries, and history securely to a user database.
