# Lauraineai

Build an AI workspace assistant that helps professionals carry out tasks and does it automatically. The key features are:
- Generating contextual-based emails, refining the tones, and creating quick responses based on brief prompts
- Compiling meeting notes into executive summaries, key decisions and updates
- Planning tasks and extracting information about deadlines, extracting action items from meeting notes or emails and dynamically organizing them into the calendar or a priority-based list.
- Built-in Persistence that saves your previously generated tasks, summaries, and history securely to a user database.

Requirements are:
- A modern dashboard with a UI that has the perfect balance of the Glassmorphism and Neumorphism style.
- A side Navigation Bar
- Responsive Design
- Structured prompts for AI
- AI Outputs that can be edited
- Disclaimer to use AI responsibly
- State Management: the software must retain active text inputs or generated outputs even if the user switches tabs
- Input Context Field for raw context or quick notes
- Tone Selection Dropdown
- A dedicated "Copy to Clipboard" button
- Bulk text input
- A planner "Export" button
- A visual interface showing tasks split by status (To Do, In Progress, Completed)
- Users must be able to change a task's status, delete a task, or manually type in a new one
- Connection to a foundational model like GPT-4o
